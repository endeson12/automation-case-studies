# Security Policy

Este repositório publica apenas documentação sanitizada.

## Não publique

- credenciais, tokens, cookies ou arquivos `.env`;
- dados pessoais, documentos ou informações de usuários;
- nomes, valores ou registros operacionais de empresas;
- capturas de tela que revelem contas, campanhas ou identificadores internos;
- código privado copiado dos sistemas descritos.

Relate exposições de forma privada pelo contato disponível no perfil do autor. Não abra uma issue contendo o dado sensível.
