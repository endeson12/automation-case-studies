# Estudos de Caso — Automações, APIs e Sistemas Inteligentes

Portfólio técnico de Endeson Marcell com cinco projetos reais. Os estudos descrevem problema, arquitetura, automações, controles e evidências reproduzíveis sem publicar credenciais, dados empresariais ou informações de usuários.

> Projetos internos permanecem com código privado. Nestes casos, a documentação pública apresenta somente arquitetura sanitizada, responsabilidades técnicas e limites comprováveis.

## Projetos

| Projeto | Foco | Stack | Evidência pública |
|---|---|---|---|
| [Geo Intelligence API](cases/geo-intelligence-api.md) | ingestão e análise territorial automatizada | FastAPI, PostGIS, GeoJSON, Docker | [código](https://github.com/endeson12/geo-intelligence-api) · [demo](https://endeson12.github.io/geo-intelligence-api/) |
| [DevOps FastAPI Lab](cases/devops-fastapi-lab.md) | entrega, observabilidade e recuperação automatizadas | FastAPI, Docker, GitHub Actions, Prometheus | [código](https://github.com/endeson12/devops-fastapi-lab) · [Swagger](https://devops-lab.76-13-234-134.sslip.io/docs) |

| [Financial Document Automation](cases/financial-document-automation.md) | ingestão, OCR e revisão supervisionada de documentos | Python, Next.js, Supabase, OCR | estudo sanitizado |

## Princípios de engenharia

- automação com supervisão humana em decisões sensíveis;
- idempotência, rastreabilidade e proveniência;
- segredos fora do Git e redução de dados expostos;
- testes, análise estática e CI como evidência;
- limitações declaradas sem inventar clientes, escala ou métricas;
- documentação orientada a execução, operação e recuperação.
